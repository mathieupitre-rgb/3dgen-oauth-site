Politique de confidentialité

3dGen Local Drive · Dernière mise à jour : 9 octobre 2026

En bref : 3dGen Local Drive est une utilisation personnelle de rclone et de Google Drive. Les transferts de fichiers et l'authentification se font sur l'ordinateur de l'utilisateur. Cette page statique ne demande pas de connexion et ne reçoit ni mot de passe ni jeton.

1. Objet de l'application

L'application utilise un client OAuth Google pour autoriser rclone sur un PC Windows. Le système local 3dGen peut récupérer des fichiers images depuis un dossier de Google Drive choisi par l'utilisateur et les fournir à un environnement de création ComfyUI local. Elle n'est pas commercialisée comme service public.

2. Données accessibles

  • Fichiers Google Drive : noms, métadonnées et contenu des images nécessaires aux opérations autorisées. Les permissions exactes dépendent de la portée OAuth approuvée au moment de la connexion et peuvent, techniquement, porter sur un ensemble de fichiers plus vaste que le dossier ciblé par le travail local.
  • Jetons d'autorisation : jetons OAuth et données de configuration conservés dans la configuration privée de rclone sur l'ordinateur local.
  • Données opérationnelles : noms de fichiers, références de jobs, statuts techniques et erreurs assainies pouvant être inscrits dans les journaux locaux et dans la file GitHub privée du projet 3dGen.

3. Utilisation et transfert des données

Les données Drive sont utilisées seulement pour les opérations explicitement demandées par l'utilisateur, principalement la lecture et la copie d'images vers son ordinateur. Google traite les requêtes d'authentification et de fichiers nécessaires au service Drive; GitHub héberge les métadonnées de coordination de jobs, mais pas les contenus des images récupérées ni les jetons OAuth. Les fichiers peuvent ensuite être utilisés par ComfyUI localement. Aucune vente de données ni exploitation publicitaire n'est effectuée par cette intégration.

4. Stockage, durée et suppression

Les copies d'images, les journaux et la configuration OAuth sont stockés dans les répertoires privés du PC Windows et restent jusqu'à suppression par l'utilisateur ou application d'une règle locale de rétention. Les statuts de jobs dans le dépôt privé GitHub peuvent conserver des métadonnées après la fin d'un travail. Il n'existe pas de base de données centrale gérée par ce site public. L'utilisateur peut supprimer les fichiers et la configuration rclone sur son ordinateur, ainsi que les entrées pertinentes dans son dépôt GitHub.

5. Sécurité et révocation

Les identifiants du client, les jetons OAuth et les fichiers de configuration rclone doivent rester privés et ne doivent jamais être publiés sur GitHub Pages ni transmis à des tiers. Le client OAuth est utilisé localement. L'utilisateur peut révoquer l'accès depuis les paramètres de sécurité de son compte Google et supprimer le remote rclone. La révocation n'efface pas automatiquement les fichiers déjà copiés localement.

6. Ce site Web public

Ce site est statique : il ne contient ni formulaire de collecte, ni code de suivi analytique ajouté par 3dGen, ni mécanisme d'accès au compte Google. Il est hébergé par GitHub Pages. GitHub peut traiter des données techniques de visite selon sa propre déclaration de confidentialité.

7. Services tiers et changements

Les requêtes aux services de Google sont assujetties aux politiques de Google. Le fonctionnement local utilise rclone, ComfyUI et GitHub pour les fonctions décrites. Si les usages ou permissions évoluent, cette politique sera mise à jour publiquement avant de représenter les nouveaux usages comme actifs.

8. Contact

Pour une question sur cette application personnelle ou cette politique, ouvrir une demande dans le dépôt GitHub public, sans y publier de données personnelles, d'identifiants OAuth ou de contenus Drive.

3dGen Local Drive est une intégration indépendante. Elle n'est ni développée ni approuvée par Google.
